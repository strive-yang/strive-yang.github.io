# Bootstrap Project Contract 展示图

- `bootstrap-contract-overview.svg`：项目页和首页使用的原生矢量流程示意，1080 × 760。
- `bootstrap-contract-overview.png`：由同名 SVG 离线渲染的分享图，1080 × 760。
- `bootstrap-contract-card.svg`：项目索引使用的简化版本，1080 × 270，聚焦三个主要决策节点。

这些图说明“读取仓库证据 → 选择最低充分等级 → 最小契约动作”的关系，不是实际软件界面或特定仓库的运行报告。主图的 Level 1 是带有明确需求的示例；实际判断必须从 Level 0 开始，复用和无需修改也是有效结果。

图中文字与布局使用 SVG 编写，没有使用旧的抽象生成图。原图 `bootstrap-contract-hero.webp` 保留为历史素材，当前页面不再展示。
