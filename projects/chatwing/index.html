01 / Find your way back

回到那次提问，
也找回当时的上下文。

每个目录项对应一次用户提问。把鼠标移到页面右侧即可展开，需要持续回看时，也可以固定面板。

01

先预览，再决定跳转

悬停目录项，阅读完整提问与回答开头。长内容可以在预览面板中滚动，当前阅读位置保持不变。

02

点击定位，快速确认

点击后回到对应提问，并短暂高亮消息。目录标出当前阅读位置，也支持键盘导航。

03

展开与固定，各有节奏

平时收在页面右侧，使用时展开；固定后可以连续回看。明暗主题跟随页面，兼顾不同阅读习惯。

在对话旁边，留一条回看的路。

新提问、生成中的回答、提问编辑与聊天切换都会触发更新。对于延迟渲染的长对话，可通过滚动补全消息，再恢复阅读位置；补全操作也可以中止。

03 / Install in Chrome

下载、解压，
加载到 Chrome。

当前通过 GitHub Release 提供扩展 ZIP，安装和运行无需构建。首次使用请按以下步骤手动加载。

  1. 01

    下载扩展 ZIP

    进入最新发行页 ↗，下载 ChatWing-<版本>.zip 附件并解压。当前已发布版本为 v0.1.2。

  2. 02

    打开扩展管理

    在 Chrome 地址栏打开 chrome://extensions，开启右上角的“开发者模式”。

  3. 03

    加载解压目录

    点击“加载已解压的扩展程序”，选择包含 manifest.json 的目录。安装后请保留该目录。

  4. 04

    刷新 ChatGPT 页面

    打开或刷新一段 ChatGPT 对话，将鼠标移到页面右侧，开始使用提问目录。

更新时怎么做？

用新版文件替换 Chrome 当前已加载目录的内容，在扩展管理中点击 ChatWing 卡片上的刷新按钮，再刷新 ChatGPT 页面。若改用新目录，可先移除旧扩展，再加载新目录。更多操作请查看使用指南 ↗。

04 / Scope & implementation

只围绕当前聊天，
把辅助阅读做轻。

ChatWing 在当前页面内存中处理聊天文字，不上传、不持久保存。扩展不读取登录令牌，也不调用私有 API。

原生 JavaScript + CSSShadow DOM 隔离textContent 文本展示
实现方式与测试说明 ↗

使用范围与验证边界

  • 面向当前聊天分支的文字，不检索其他聊天，也不识别图片、附件和语音。
  • 采用 Manifest V3 内容脚本，在 ChatGPT 匹配域名运行，不申请 cookies、tabs、storage 等额外权限。
  • 验证基于本地模拟页面。真实站点的结构变化、延迟加载消息，可能影响目录识别和补全。
