01 / Design principle

先理解仓库，再建立约定。

每一个新增文件、每一次修订，都应回答一个已经识别的问题。

01

从真实证据开始

查看代码、配置、测试和已有指令，区分仓库实际行为与文档描述，找到当前的协作边界。

02

选择足够的等级

从 Level 0 开始判断。只有低一级无法解决当前问题时，才增加规范、计划或作用域策略。

03

保留已有的有效规则

优先复用，必要时修订。已有约定已经足够时，保留现状就是完整且有效的结论。

02 / Lowest sufficient level

停在第一个足够的等级。

等级对应协作与风险需要。每次升级，都需要说明低一级为什么不够。

  1. Level 0判断起点

    保持现状

    默认行为或既有约定已经足够，无需新增治理。

    No additional governance required
  2. Level 1

    轻量契约

    用简洁、持久化的说明解决边界问题，通常最多增加 1–2 个产物。

  3. Level 2

    结构化协作

    持续协作需要独立的规范角色、计划或作用域策略时，再建立对应结构。

  4. Level 3

    正式治理

    用于审计、合规、严格追踪、高风险审批或明确的多团队边界。

每个候选产物，选择一个动作。
create 创建reuse 复用revise 修订skip 跳过ask 询问

03 / How it works

把判断过程，留得可验证。

先分清现状、目标与规范来源，再决定写入的范围和方式。

  1. 01

    发现证据 Discover

    扫描代码、配置、测试、文档与既有 Agent 指令。

  2. 02

    判断状态 Classify

    分别判断项目成熟度、当前治理状态和交付模式。

  3. 03

    明确角色 Resolve roles

    划清规范权威、实现证据和描述文档的边界。

  4. 04

    选择等级 Select level

    从 Level 0 开始，停在第一个足够的等级。

  5. 05

    检查写入条件 Write gate

    根据风险判断直接写入、请求确认或暂停。

  6. 06

    完成最小修改 Write minimally

    只改必要内容，保留已有规范，并让重复运行保持幂等。

  7. 07

    验证结果 Validate

    核对权威唯一性、链接、安全、平台假设与二次运行结果。

Repository knowledge

三类知识，各自回答一个问题。

A / 规范权威

应该是什么？

需求、策略、计划、架构决策与作用域规范。

B / 实现证据

实际是什么？

代码、配置、测试、Manifest 与安全的运行检查。

C / 描述文档

如何向人解释？

README、运维说明、入门文档与参考页面。

判断时标明 verified 已验证、designed 设计目标、unknown 未知，保留证据边界。

04 / Put it to work

选一个场景，交给你的 Agent。

该 Skill 默认需要显式调用。安装完整目录后，复制对应提示词，在目标仓库中使用。

01 / New repository

新项目接入 Agent

先判断项目需要什么，再建立必要的起步契约。

Use $bootstrap-project-contract to inspect this new repository and establish the minimum Agent governance it actually needs.
02 / Existing repository

已有项目重新评估

识别事实来源、冲突与漂移，只补缺失的契约片段。

Use $bootstrap-project-contract to reassess this repository's current governance, identify the source-of-truth files, and add only the missing Agent contract pieces.
03 / Review governance

检查是否治理过度

推荐最低充分目标；删除或迁移现有权威前需要确认。

Use $bootstrap-project-contract to determine whether this repository is over-governed. Recommend the lowest sufficient target contract and do not delete or migrate existing authorities without confirmation.
