01 / Know your quota

少一次切换，
多一份心里有数。

由本机 Codex CLI App Server 读取账户额度，按窗口时长识别 5H / 7D。数字和进度条都表示剩余百分比。

5H / 7D

两个窗口，分别掌握

58% 表示该窗口还剩 58%。点击额度条可查看剩余与已用比例、重置时间、倒计时和更新时间；更多额度桶进入“全部详情”。

Refresh & cache

读数有来源，也有时效

默认约 5 分钟刷新，可设为 5–60 分钟。上次成功读数会缓存在本地；历史缓存、过期、读取失败和缺失窗口都有相应标记。

02 / Find your place

选一个顺手的位置。

在设置中切换显示方式，调整明暗主题、位置锁定与刷新间隔。

01 Default

任务栏常驻

在桌面任务栏内部显示额度条。默认面向主屏、居中、底部布局，并为天气区域预留空间。

02 Flexible

独立浮窗

将额度条拖到顺手的位置，支持锁定与恢复默认位置。任务栏空间不足时，也可以切到浮窗。

03 Minimal

仅系统托盘

把入口收在托盘，点击查看详情，右键打开设置。图标也可能收在“显示隐藏图标”中。

03 / Get started

登录、解压、运行。

首版提供 Windows x64 便携包，无需管理员权限。开始前，需要在本机安装并登录 Codex CLI。

  1. 01

    准备本机 Codex CLI

    在 Windows 原生 CMD 或 PowerShell 中安装并完成登录，确认 codex --version 可用。

  2. 02

    下载并解压便携包

    从 GitHub Releases ↗ 获取 Windows x64 ZIP，解压到固定目录。可对照同一 Release 的 SHA256SUMS.txt 校验文件一致性。

  3. 03

    启动 QuotaRail

    双击解压后的 quotarail.exe。点击额度条查看详情，右键额度条或托盘图标进入设置。

使用前了解兼容性

当前为早期 Beta；首版没有安装器、自动更新或代码签名。默认任务栏模式支持主屏、居中、底部布局；绑定失败时会保留托盘并提示原因，可在设置中切换浮窗或仅托盘。其他布局请先查看兼容性与已知限制 ↗。

Local by design

额度在眼前，
数据留在本机。

QuotaRail 不自行读取或保存认证令牌，不创建模型任务，不收集提示词或代码。认证与额度请求交由本机 Codex CLI 处理，设置与历史额度缓存在本地。
